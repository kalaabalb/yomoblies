# Security Policy

## Supported Versions

The repository currently tracks the latest `main` branch only.

## Reporting a Vulnerability

If you discover a security issue, do not open a public issue with exploit details.

Report it privately with:

- A description of the issue
- Impact and reproduction steps
- Relevant logs or screenshots
- Suggested mitigation if available

## Notes

- Do not commit API keys, tokens, or credentials
- Keep backend URLs and environment-specific values configurable
- Review storage of user data before adding new sensitive fields
