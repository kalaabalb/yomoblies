# Contributing

Thanks for taking the time to improve this project.

## Workflow

1. Fork or branch from `main`
2. Make a focused change
3. Run `dart format --set-exit-if-changed .`, `flutter analyze`, and `flutter test`
4. Open a pull request with a concise summary and screenshots when relevant

## Guidelines

- Preserve existing behavior unless the change is explicitly intended to improve it
- Keep UI changes consistent with the current app language and design system
- Avoid introducing new dependencies unless they are clearly needed
- Prefer small, reviewable pull requests

## Reporting Issues

- Include the screen, expected behavior, and actual behavior
- Attach logs or screenshots when useful
- Mention device, OS, and Flutter version if the issue is environment-specific
