# Code of Conduct

This project is intended to be a professional, collaborative open-source repository.

## Expected Behavior

- Be respectful and constructive
- Focus feedback on code, design, and product behavior
- Assume good intent until evidence suggests otherwise
- Keep discussions relevant to the repository

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory language
- Personal attacks
- Deliberate disruption of reviews or issue discussions
- Posting secrets or private user data

## Enforcement

Project maintainers may close issues, reject pull requests, or remove access when behavior is harmful to the project or its contributors.
